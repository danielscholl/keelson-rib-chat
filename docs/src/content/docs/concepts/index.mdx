## Where a swarm fits

| Mode | Use it for |
|---|---|
| **Chat with one agent** | Fast, open-ended work where one context is enough |
| **Workflow** | Repeatable execution with known steps |
| **Chamber room** | A fixed roster taking turns over one transcript |
| **Swarm** | Parallel, read-only investigation by agents that have to find and reach each other |

A swarm and a [Chamber](https://danielscholl.github.io/keelson-rib-chamber/)
room look alike from a distance, and they are built on opposite assumptions. A
room has one driver that routes every turn and deliberately has no message bus.
A swarm has no driver: agents work independently and in parallel, so they need a
bus, and ClickClack is that bus. Pick a room when you know who should speak and
in what order. Pick a swarm when you do not yet know how the work divides.

A swarm investigates. It does not implement. To act on what a swarm concludes,
run an implementation workflow yourself and carry the conclusion into it.
